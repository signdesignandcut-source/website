Activate with a file

For Sign Design and Cut on a PC with no internet.

  1. On that PC, the program saved a request file (activation-request.sdcreq).
  2. Put it in the box below and click Get my license file.
  3. Take the license file (license.sdclic) back to that PC and load it in the program.

Freeing a PC you no longer use? Put its release file (activation-release.sdcrel) in the box instead.
